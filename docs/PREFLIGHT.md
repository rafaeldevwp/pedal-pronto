# Preflight obrigatório

Execute esta lista antes de alterar o produto.

## 1. Entender

- Ler `PROJECT_MEMORY.md`.
- Identificar a única tarefa `NEXT` em `docs/TASKS.md`.
- Ler apenas a SPEC e as decisões de design relacionadas.
- Declarar o que será feito e o que ficará fora.

## 2. Verificar estado

- Conferir alterações locais antes de editar.
- Não sobrescrever trabalho incompleto.
- Confirmar se a última versão está publicada ou apenas local.
- Conferir conexões, dados e efeitos externos envolvidos.

## 3. Segurança funcional

- Definir quais dados serão somente leitura.
- Definir exatamente qual treino pode mudar.
- Garantir confirmação para alterações futuras.
- Garantir comportamento seguro para dados incompletos.
- Verificar limites semanais e dias de descanso.

## 4. Entrega

- Implementar uma tarefa por vez.
- Validar build e fluxos afetados.
- Publicar somente após validação.
- Atualizar `PROJECT_MEMORY.md`, `docs/TASKS.md` e, se necessário, `docs/DESIGN.md`.
- Registrar o próximo ponto de retomada em uma frase.
